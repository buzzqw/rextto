Importa una copia di legacy

Rextto non comunica con legacy e non legge i suoi database operativi. Importa solo copie locali create per la migrazione.

1. Ferma legacy
sudo systemctl stop legacy.service
2. Prepara la copia
cd /home/user/rextto && ./prepare-rextto-import.sh
I quattro database vengono copiati in .
3. Importa in Rextto
Viene creato uno snapshot di audit e vengono inizializzati i database nativi.

legacy deve restare spento prima di avviare Rextto sulle porte 5000 e 8889.
